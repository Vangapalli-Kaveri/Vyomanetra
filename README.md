# Drone Detection AI using YOLOv8

## Overview
This project detects drones in images, videos, and webcam streams using a custom-trained YOLOv8 model.

## Technologies
- Python
- YOLOv8
- PyTorch
- OpenCV
- Roboflow
- CUDA
- NVIDIA RTX 3050

## Features
- Drone detection in images
- Drone detection in videos
- Real-time webcam detection
- Custom dataset training

## Run

Train:
python train.py

Image Detection:
python predict.py

Video Detection:
python predict_video.py

Webcam Detection:
python detect_webcam.py
